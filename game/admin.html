The marketplace region is where your visitors are, and decides which datasets get recommended. It is not this account's region, which you never need to know.

Check “datasets loaded” before doors open. It should be 90–96 for the chosen city. If it reads 0, this city's datasets never reached the account and the stall will quietly serve London's instead — re-run deploy/load_context.py. If “lists read from” says bundle or markdown rather than snowflake, the account read failed and you are on a committed copy that may be out of date.

Setup check

Run this before doors open. It proves the delivery chain end to end: the snow CLI resolves, the stage is reachable, a document can be staged and presigned, and the booth connection is on key-pair — so no password or browser prompt interrupts a visitor. Read-only; the only side effect is a tiny probe file staged and presigned.

Recover

Clear visitor wipes the current session and recycles the agent — the normal between-visitors action. Restart replaces the whole process: only needed if replies have stopped coming back, or you edited server.py. It takes a few seconds and the first reply afterwards is slow.
